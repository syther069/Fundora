- **Spring** — growth, funding seeds, builders springing into action

It's already the contract name (`ProofSpring`), the localStorage key prefix (`proofspring:`), the explorer URL, and the `AGENTS.md` title. Changing it now would mean renaming the deployed contract (not possible without redeployment), the Solidity file, and all references across the codebase.

- **GrantFlow** — clean, descriptive, self-explanatory

- **BuildProof** — builder-first framing
- **Verdify** — verdict + verify, reviewer-focused
- **SeedVault** — funding + trust angle

But honestly, ProofSpring is distinctive and already consistent across the whole codebase. I'd keep it.
